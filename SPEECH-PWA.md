# Speaking practice and PWA

Speaking recognition is entirely local: Transformers.js 3.8.1, ONNX Runtime WASM (one thread), multilingual `onnx-community/whisper-base`, q8, pinned revision 1846881b6b3a3024392c1eea3ad983695bc23925. Weights/tokenizer are fetched from Hugging Face only after a parent enables the helper. About 110 MB including runtime. Model and runtime reuse browser Cache Storage; browser storage eviction may require another download. There is no transcription endpoint, upload, API key or usage charge for recognition. Teacher TTS remains the existing OpenRouter service.

The child explicitly starts each recording, capped at 6 seconds. Navigating, cancelling, backgrounding or starting teacher audio releases microphone tracks. Recorded data is held transiently in memory, transferred to a worker, and never persisted. Silence is screened before inference. Matching preserves Thai tones/vowels and has no target-word prompt. A match indicates only that the transcript contains the intended word, not correct pronunciation. Short-word Thai and children's speech are unreliable with small Whisper models; do not use results as a grade. Retry is optional and cannot block lessons.

PWA: first-use install banner, iOS Safari illustrated manual instructions, Android deferred install prompt when available, standalone manifest and icons. The service worker saves lessons and 44 original Thai recordings, then caches successful fixed teacher clips as used. Model weights are opt-in, not in shell precache. New workers wait for old windows to close, avoiding mid-lesson reload. Bump VERSION in dist/sw.js with every changed shell release. Browser/standalone storage may differ, especially iOS; progress is not cloud-synced.

Validation: `node --test tests/*.test.mjs`, `node check-assets.cjs`. `tests/browser-qa.html` runs a synthetic teacher audio fixture through the actual browser worker without microphone access. Serve the checkout, open this test page, and click Load then Recognize. Real iOS/Android hardware and live child recordings still require device acceptance testing.
